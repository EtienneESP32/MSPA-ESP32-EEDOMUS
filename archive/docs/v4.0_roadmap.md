# Rapport d'Évolution : Architecture "Safe-Pilot" (v6.x)

Ce document confirme l'atteinte des objectifs de monitoring et de verrouillage sécurisé.

## Étape 1 : Infrastructure Pro (Release 4.0) - TERMINÉ
**Statut** : COMPLÉTÉ.
- Migration de la logique UART vers le composant C++ `mspa_uart`.
- Implémentation du **Forwarding asynchrone** (Zero-Lag).

## Étape 2 : Monitoring & Intent (Release 4.1-5.x) - TERMINÉ
**Statut** : COMPLÉTÉ.
- Synchronisation bidirectionnelle de la température et de la consigne.
- L'interface Web et Eedomus reflètent désormais l'état réel du bus.

## Étape 3 : Le Firewall Sélectif (Release 6.x) - TERMINÉ
**Statut** : COMPLÉTÉ.
- Ajout de l'entité `lock_keypad` (Verrouillage Clavier).
- Logique de filtrage active : les commandes clavier sont ignorées si verrouillées, seul le heartbeat `0x0D` circule.

## Étape 4 : Intégration Eedomus (Release 6.3.4) - TERMINÉ
**Statut** : COMPLÉTÉ.
- Push asynchrone (HTTP 1s timeout) opérationnel.
- Stabilité WiFi garantie même pendant l'activité UART intense.
